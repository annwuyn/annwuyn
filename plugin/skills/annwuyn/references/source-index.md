# Source index

The reference library in this folder is a distillation of a 38-session Vietnamese academic-writing
curriculum (3 modules), Contrastive-Rhetoric-based, focused exclusively on academic writing and the
**argumentative genre**. This file maps each reference file back to the session materials it came
from, so any point can be cross-checked against the original handouts.

Source folder on this machine: `<Drive>/Personal/<course folder>/S<n> materials/`
Third-party works whose frameworks or tables are used: see `SOURCES.md`.

## Curriculum goals (S1)

The curriculum's aim: help Vietnamese learners **notice and shorten the gap** between their own English and that of
native writers — 'block building' for academic writing, both technically and culturally
problematic to Vietnamese learners.

**Macro-structure**: Awareness raising → Discovery (essay comparison by rhetorical development;
negative L1 transfer) → Revision (self- and peer-review) → Application (standardized tests,
scholarship applications, school assignments, research proposals and academic publications,
work reports and funding proposals).

Application ladder: TOEFL/IELTS ≪ SAT ≪ GRE/GMAT/LSAT ≪ academic assignments ≪ scholarship
applications ≪ publications ≪ professional reports.

**Multi-system approach to grammar**: Structural (rules) + Functional (writer's purposes) +
Cognitive (semantic networks). Linking is viewed from all three.

## Recurring exemplar texts

The course reuses a small set of texts across modules; recognising them speeds up any lookup:
Joel Brinkley, *Despite increasing prosperity, Vietnam's appetites remain unique* (the
response-writing target, S9 onward) · Text A / Text B "bad luck" essay pair (S2, S7–S8) ·
the Uyên Linh paragraph (S1, S9) · *Học để làm giàu tri thức* (S7) · the kids-and-extra-classes
paragraph (S2–S6).

## Lecture audio — not processed

Each session folder also contains lecture recordings: **65 MP3 files, ~9.5 GB total**, usually
two per session ("from recorder" and "from camera output"). They are **not** transcribed and are
not reflected in these references — this library is built from the 132 PDFs and one DOCX only.

The slides are deliberately sparse: many carry only a heading plus *"→ watch sample clips"*,
*"FOOD FOR THOUGHT"*, or an unlabelled diagram. The reasoning behind those slides lives only in
the audio. Expect gaps in: worked answers demonstrated verbally, the sample-clip analyses, most
"Food for thought" prompts, and the S38 live application review.

To close the gap, transcribe locally (no transcription tool is currently installed on this
machine) — e.g. `whisper.cpp` or MacWhisper with a Vietnamese/English multilingual model — then
add per-session transcript notes alongside these files.
