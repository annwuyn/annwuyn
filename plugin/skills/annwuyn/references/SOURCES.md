# Sources

**This compilation** — the skill structure, the staged pipeline, the diagnostic checklists, the
worked orderings and all prompt text in these files — © annwuyn.

The **linguistic frameworks and reference tables** it draws on are the work of others, listed
here so nothing in this library is mistaken for original scholarship. Cite these, not this
library, in academic work.
